# 💼 Job Portal

> A full-stack recruitment management system built with ASP.NET MVC, C#, Entity Framework, and Microsoft SQL Server.

---

# 📖 Overview

The **Job Portal** is a web-based recruitment platform designed to streamline the hiring process by connecting employers and job seekers through a centralized system. Employers can create and manage job postings, while candidates can register, browse opportunities, apply online, and track their applications. The project follows the **Model-View-Controller (MVC)** architecture, ensuring clean code organization, scalability, and maintainability.

The application demonstrates real-world implementation of authentication, role-based authorization, CRUD operations, database integration, and responsive web design. It serves as a practical example of building enterprise-level web applications using Microsoft's development stack.

---

# ✨ Features

## 👤 Candidate Module
- Secure user registration and login
- Browse and search available jobs
- View detailed job descriptions
- Apply for multiple job positions
- Track submitted applications
- Update personal profile

## 🏢 Job Management
- Create, edit, and delete job postings
- Manage job categories
- Display complete job information
- Organize listings efficiently

## 🛠️ Admin Dashboard
- Manage users and job listings
- View candidate applications
- Perform complete CRUD operations
- Monitor system activity

## 🔒 Authentication & Security
- Role-based access control
- Session management
- Server-side validation
- Protected admin routes
